Política de Privacidade e Proteção de Dados

Entenda como a ClinicWise coleta, utiliza, armazena e protege as informações pessoais de seus usuários e pacientes.

Última atualização: 18 de Julho de 2026

1. INTRODUÇÃO E COMPROMISSO

A ClinicWise preza pela manutenção da privacidade e segurança de seus dados. Esta Política de Privacidade reflete nosso compromisso em tratar os dados pessoais de nossos Usuários com segurança, privacidade e, acima de tudo, transparência.

A ClinicWise LTDA, sediada no Rio de Janeiro - RJ, atuando no escopo de suas atividades como operadora e, em determinados cadastros diretos, como controladora de dados pessoais, estabelece as diretrizes de privacidade regidas pela legislação nacional, em especial a Lei Geral de Proteção de Dados Pessoais (LGPD - Lei nº 13.709/2018).

2. DEFINIÇÕES IMPORTANTES

Para simplificar o entendimento desta Política, adotamos as seguintes nomenclaturas:

  • Dado Pessoal: Qualquer informação que se refira a uma pessoa natural (física) identificada ou identificável (por exemplo: nome, e-mail, CPF, telefone).
  • Dado Pessoal Sensível: Dados que tratam de aspectos íntimos do indivíduo, como dados sobre a saúde (prontuários, anamnese, exames), origem étnica, convicções religiosas ou dados genéticos/biométricos.
  • Tratamento: Qualquer operação realizada com dados pessoais (como coleta, armazenamento, processamento, visualização, exclusão ou compartilhamento).
  • Controlador: Aquele a quem competem as decisões sobre o tratamento de dados pessoais (neste caso, o Usuário contratante/clínica ao gerir dados de seus pacientes).
  • Operador: Aquele que realiza o tratamento de dados em nome do Controlador (neste caso, a ClinicWise ao prover o software de nuvem e ferramentas de armazenamento).

3. DADOS COLETADOS E FINALIDADE

A ClinicWise coleta dados em dois contextos distintos de utilização:

3.1. Dados dos Usuários Contratantes (Profissionais de Saúde e Clínicas)

Para criação de conta, emissão de faturamento e suporte, coletamos:

  • Nome completo, e-mail, telefone comercial, CPF ou CNPJ da clínica.
  • Número do registro de conselho de classe profissional (CRM, CRO, CRP, CREFITO, CRN, etc.).
  • Dados de pagamento e dados de faturamento.

Finalidade: Viabilizar a execução do contrato de licença do software, prestar suporte técnico, enviar avisos de segurança e realizar cobranças.

3.2. Dados dos Pacientes (Inseridos pelos Usuários)

O Usuário utiliza a plataforma para registrar dados de seus Pacientes, incluindo:

  • Dados básicos: Nome, idade, e-mail, telefone celular para confirmação de consultas.
  • Dados de saúde (sensíveis): Ficha de anamnese, registros de prontuário, planos de tratamento, prescrições e imagens de exames.

Finalidade: Armazenar de forma segura o histórico de atendimento dos Pacientes do Usuário. Neste cenário, a ClinicWise opera estritamente sob as ordens e configurações do Usuário contratante (Controlador), não utilizando esses dados para qualquer outra finalidade própria.

4. DIREITOS DOS TITULARES DE DADOS

A ClinicWise garante aos titulares de dados pessoais o pleno exercício de seus direitos previstos pela LGPD, incluindo:

  • Confirmação da existência de tratamento de seus dados.
  • Acesso facilitado aos dados armazenados.
  • Correção de dados incompletos, inexatos ou desatualizados.
  • Eliminação dos dados pessoais tratados com o consentimento do titular (salvo hipóteses legais de retenção de prontuário de saúde).
  • Portabilidade dos dados.

Para dados de Pacientes, a solicitação deve ser feita diretamente ao profissional de saúde ou clínica (Controlador), cabendo à ClinicWise colaborar prontamente com a exclusão ou exportação solicitada pelo Usuário.

5. SEGURANÇA DAS INFORMAÇÕES

Adotamos medidas rígidas de segurança técnica e administrativa para resguardar a integridade e privacidade de todos os dados armazenados na plataforma:

  • Uso de criptografia ponta a ponta na transmissão dos dados (SSL/HTTPS).
  • Armazenamento em infraestrutura de nuvem segura com controles de acesso granular e restrito.
  • Backup diário estruturado para assegurar a recuperação rápida de dados em caso de sinistros.
  • Auditoria interna de logs de acesso e modificações na plataforma.

6. COMPARTILHAMENTO COM TERCEIROS

Os dados tratados pela ClinicWise não são divulgados, cedidos ou comercializados a terceiros em nenhuma hipótese. O compartilhamento ocorre apenas:

  • Com provedores de tecnologia parceiros essenciais para o funcionamento do sistema (como servidores de hospedagem na nuvem e gateways de pagamento seguros), sob rigoroso dever contratual de confidencialidade.
  • Para o disparo de lembretes via SMS/WhatsApp quando ativado pelo Usuário.
  • Em cumprimento de ordem judicial ou obrigação regulatória.

7. RETENÇÃO E EXCLUSÃO

Os dados dos Usuários e seus Pacientes são mantidos na ClinicWise enquanto a assinatura do serviço estiver ativa. Em caso de cancelamento, a ClinicWise resguarda a guarda das informações pelo prazo regulatório de prontuários de saúde (e conformidade civil), fornecendo ferramentas de backup para o Usuário extrair seus registros antes da eliminação definitiva.

9. ALTERAÇÕES NESTA POLÍTICA

Esta Política de Privacidade poderá ser modificada periodicamente para refletir novas funcionalidades do sistema ou atualizações das autoridades reguladoras (ANPD). Mudanças substanciais que afetem as finalidades de uso serão informadas aos Usuários cadastrados por e-mail com antecedência.
